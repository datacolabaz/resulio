☕ JAVA BACKEND DEVELOPER – 6 AYLIQ PROQRAM

Müddət: 6 ay
Format: Həftədə 3 dərs (2 saat)
Səviyyə: Başlanğıcdan orta səviyyəyə
Məqsəd: Tələbəni Spring Boot ilə real backend layihələri yaza bilən Junior Java Developer səviyyəsinə çatdırmaq.

---

🔹 1-ci AY — Java Fundamentals & Programming Basics

Mövzular:
- Java nədir, JDK, JRE, JVM
- IntelliJ IDEA quraşdırılması və ilk proqram
- Dəyişənlər, data tipləri və operatorlar
- Şərt operatorları (if/else, switch)
- Dövrlər (for, while, do-while)
- Massivlər və String ilə iş
- Metodlar və parametrlər

Praktiki layihə:
- Konsol kalkulyatoru
- Tələbə qiymətləri hesablayıcısı

Məqsədlər:
- Java sintaksisini sərbəst istifadə etmək
- Sadə alqoritmləri kodla həll etmək

---

🔹 2-ci AY — Object-Oriented Programming (OOP) & Java Core

Mövzular:
- Class və Object
- Constructor, this, static
- Encapsulation, Inheritance, Polymorphism, Abstraction
- Interface və abstract class
- Exception handling (try/catch/finally, custom exceptions)
- Wrapper class-lar və autoboxing
- Collections Framework: List, Set, Map

Praktiki layihə:
- Kitabxana idarəetmə sistemi (konsol)

Məqsədlər:
- OOP prinsiplərini real nümunələrdə tətbiq etmək
- Collections ilə məlumatları idarə etmək

---

🔹 3-cü AY — Advanced Java, File Handling, Streams & Database Fundamentals

Mövzular:
- Generics
- Lambda ifadələri və Functional Interface-lər
- Stream API (filter, map, reduce, collect)
- Optional
- Fayllarla iş (java.io, java.nio)
- Multithreading əsasları
- SQL əsasları: SELECT, JOIN, GROUP BY
- PostgreSQL və JDBC

Praktiki layihə:
- İşçi məlumatlarını fayldan oxuyub bazaya yazan tətbiq

Modul üzrə qiymətləndirmə:
- Kod keyfiyyəti
- SQL sorğularının düzgünlüyü
- Layihənin təqdimatı

---

🔹 4-cü AY — Software Design, Clean Code & Spring Framework

Mövzular:
- SOLID prinsipləri
- Design Patterns: Singleton, Factory, Builder, Strategy
- Clean Code qaydaları
- Maven / Gradle
- Spring Core: IoC, Dependency Injection
- Spring Boot ilə ilk tətbiq
- Spring Data JPA və Hibernate

Praktiki layihə:
- Online mağaza üçün məhsul kataloqu (Spring Boot + JPA)

İlkin tələblər:
- OOP və Collections biliyi
- SQL əsasları

---

🔹 5-ci AY — REST APIs, Spring Security & Testing

Mövzular:
- REST prinsipləri və HTTP metodları
- Spring Web: Controller, Service, Repository qatları
- DTO, Validation, Exception Handler
- Swagger / OpenAPI
- Spring Security: authentication, authorization
- JWT ilə giriş
- Unit test: JUnit 5, Mockito
- Integration testlər

Praktiki layihə:
- Tapşırıq idarəetmə REST API (JWT + testlər)

---

🔹 6-cı AY — Deployment, Docker & Final Project

Mövzular:
- Git və GitHub workflow
- Docker və Docker Compose
- CI/CD əsasları (GitHub Actions)
- Cloud-a deploy
- Logging və monitoring

Final Project:
Tələbə seçdiyi mövzuda tam backend layihəsi hazırlayır:
- E-commerce backend
- Kurs qeydiyyat sistemi
- Restoran sifariş sistemi

Modul üzrə qiymətləndirmə:
Final Project
Layihə mərhələləri: Analiz → Dizayn → Kod → Test → Deploy
Qiymətləndirmə meyarları:
- Arxitektura
- Kod keyfiyyəti
- Testlər
- Təqdimat
