# Resulio.co — Design Direction

## Theme Name
**Exam-first Clarity**

A focused education product that feels precise, modern, and calm. The interface should make the next exam action obvious, never busy.

Chosen because Resulio is exam-first: create, share, sit, score, improve. Visual noise would compete with the timer, questions, and analytics.

Probability notes (rejected alternatives, each <0.10):
- Neon classroom gamification: 0.04
- Academic parchment / university crest: 0.06
- Pure dark developer console: 0.07

## Design movement
Swiss-modern educational SaaS with a geometric identity. Clean grids, generous whitespace, one strong action per screen.

## Core principles
- Low cognitive load
- One primary CTA visible: Yeni imtahan yarat
- Status always readable (draft / scheduled / active / completed)
- Teacher desktop = sidebar + content; student exam = mobile-first workspace
- Never hide grading keys in the client

## Color philosophy
- Deep navy `#0B1220` — trust, sidebar, exam chrome
- Paper `#F7F8FB` — working surface
- Ink `#111827` — primary text
- Cyan `#00C2D7` — progress, active, success
- Amber `#F4A261` — attention, deadlines, weak topics
- Coral `#E85D4C` — errors / difficult questions
- White cards with 1px `#E5E7EB` borders

## Layout paradigm
12-column desktop grid. Sidebar 272px. Content max-width 1180px. Student exam is a two-pane workspace on desktop and a single-column sticky-action layout on mobile.

## Signature elements
- Geometric Resulio mark: an open book forming an “R” with a check-gap in negative space
- Cyan 3px top accent on app chrome
- KPI tiles with oversized Space Grotesk numbers
- Translation tabs AZ / RU / EN with completeness dots

## Interaction philosophy
Optimistic save for answers and drafts. Confirm only on publish, submit, revoke access, and role choice. Timer and autosave status are always visible during an exam.

## Animation
None beyond CSS state. No decorative motion. Instant navigation.

## Typography
- Headings: Space Grotesk
- Body / UI: Inter
- Code / IDs: JetBrains Mono or system mono
- Minimum body 14px in app, 16px in exam workspace

## Brand essence
Clarity that turns teaching into measurable progress.

## Brand voice
Direct Azerbaijani-first UI, with RU/EN parity. Short verbs. No playful slang during exams.

## Wordmark / logo
Wordmark: **Resulio** in Space Grotesk Medium. Mark: navy square with cyan open-book/R silhouette. Favicon uses the same square mark. No letters inside the mark.

## Signature brand color
Cyan `#00C2D7` on navy `#0B1220`.
